# GONE Fishing 私人多人模組 Beta 0.1

更新日期：2026-11-25（Asia/Taipei）。房主與朋友都需要安裝相同版本。

這是待雙人實測版本。已通過實際 Lua 程式的離線測試與模擬兩位玩家同步，尚未證明 Steam 連線、伺服器物理或遠端賭博效果正確。單人測試成功不能代表新同步程式已通過多人驗證。

## 朋友安裝

1. 雙方完整關閉遊戲。將 ZIP 完整解壓到一般資料夾。
2. 朋友執行 `Install.cmd`，貼上自己的 `GONEfishing\Binaries\Win64` 完整路徑。可由 Steam「瀏覽本機檔案」找到安裝位置。
3. 出現 `Installed and verified` 才算成功；保留顯示的備份路徑。權限不足時，可用系統管理員 PowerShell 執行 Install.ps1；不要停用防毒。
4. 從 Steam 正常開遊戲。不要使用 UE4SS 熱重載（Ctrl+R），更新後必須完整重開。

套件針對 Steam App 3645890、Build 26855621、UE4SS commit 682a75f103a61f4a5a8d396b9c2b43c8c1958c51。安裝程式若讀得到 Steam manifest，會檢查 build；發現不同既有 UE4SS.dll／dwmapi.dll 會停止，不會直接覆蓋。若找不到 manifest，無法自動確認 build，請自行確認雙方版本。其他模組保留，但其衝突未經驗證。不要自行改裝最新 Experimental DLL，原生 Hook 與這個特定版本配對。

## 雙人測試順序

僅在所有參與者同意的私人房間，由一人當房主（listen server）；不支援 dedicated server。

1. 房主建房、朋友加入。客戶端應收到 `Multiplayer sync connected`。若沒出現，先保留雙方 UE4SS.log，不能把本機熱鍵提示當成同步成功。
2. 朋友按數字鍵 1 一次開 2 倍跑速，再按數字鍵 2 開空中連跳；房主觀察移動是否正常、有沒有被拉回。房主接著各自切換，確認互不影響。先不要開 10 倍。
3. 關閉空中跳、跑速循環回 OFF，確認恢復。空中跳需放開空白鍵再按，跳高維持原版 1 倍。
4. 雙方先各賭一次，再分別開 F1、各連賭兩次，確認持續模式與歸屬。若無法辨識賭博物件擁有者，多人時會保留正常 RNG，不能據此宣稱一定最大獎。
5. 雙方各釣一次一般魚，再各用 F7 測一次，確認不互相觸發。最後才測 F8／F9。魚種、重量提示不能直接證明背包售價或伺服器接受結果。
6. 確認正常聊天可用。重新加入房間再確認可重新同步。發生卡住、崩潰或玩家效果串錯，停止該項測試並保留雙方日誌與對應 CrashContext／minidump。

每項回報請包含：房主或客戶端、按鍵順序、畫面結果、另一人看到的結果。這些是需要你和朋友實際操作的部分；離線測試不能取代兩台 Steam 用戶端。

## 熱鍵與啟動狀態

| 功能 | 操作／啟動狀態 |
|---|---|
| 跑速 | 數字列 1：OFF → 2x → 5x → 10x → OFF；每次啟動預設 OFF |
| 空中連跳 | 數字列 2：持續開關；每次啟動 OFF；原版 1 倍高度 |
| 賭博最大獎模式 | F1：持續開關；每次啟動 OFF；遠端效果仍待驗證 |
| 強制 hotspot | F6 開關 |
| 下一次咬鉤重抽 | F7／F8／F9：50／500／5000 次；平常 5 次；不是永久倍率開關 |
| Perks／喝酒加速／魚種重量提示 | 設定 enabled=true，會自動載入 |

所有原本功能模組及新增的 PlayerMovement、MultiplayerBridge 都已啟用；MultiplayerDiscovery 探測器已停用。每位朋友須自行裝模組才能使用本機熱鍵。Perks 在房主預設對有效的權威玩家角色套用相同效果；需要私人房間全員同意。

## 還原

朋友安裝後會在遊戲 Win64 下產生 `GFM-Coop-Backups/<UTC時間>/record.json`。完整關閉遊戲，以 PowerShell 執行套件內 `Restore.ps1`，輸入該時間資料夾完整路徑。程式會核對目前檔案與備份雜湊；若安裝後又改過檔案，會停止避免覆蓋。SaveGames 不會由安裝或還原程式修改。

此還原方式僅適用於透過本儲存庫 Install.ps1 安裝而產生的備份；其他安裝方式請使用各自的原始備份。

## 限制與風險

啟用 UE4SS／模組仍有帳號封鎖、遊戲崩潰及存檔損毀風險。遊戲商店聲明排行榜伺服器端反作弊；不刷排行榜不能保證沒有處分。未修改反作弊、排行榜或移動校正機制。

同步借用已確認簽章的聊天 RPC；訊息有固定格式、範圍檢查、序號與每玩家限流，依實際 chat component 所屬 controller 辨識玩家。nonce 用於區分連線，並非密碼或公開伺服器的安全認證。僅供相互信任的私人房間。UI 會嘗試收起控制訊息；若版本不同，可能仍看見 GFMP 開頭文字。

未知賭博 owner 不套用房主偏好。釣魚仍走本機既有流程，伺服器可能拒絕結果。喝酒完成事件、遠端魚重量／售價、賭博 pool.Owner 歸屬仍需真實多人驗證。

套件含 payload、SHA256 manifest、安裝／還原程式、原生修改來源與 MIT notices，不含遊戲主程式、個人存檔、日誌、dump 或 PDB。
